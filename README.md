# 知向教育：偏好与学习证据引导的 AI 辅学

保留原版紫色界面，新增可撤销的条件记忆、当前要求覆盖、知识追踪、候选教学动作比较、连续历史恢复、单变量分式最终式与原式条件核验、事务存储和本地 OCR。

## 启动

```bash
pip install -r requirements.txt
streamlit run app.py
```

服务器配置 `DEEPSEEK_API_KEY`（环境变量或 `.streamlit/secrets.toml`），可选 `DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL`。不要提交密钥。未配置时使用本地数学规则生成具体分式反馈；不是模型回答。

Debian/Streamlit Cloud 安装 `packages.txt` 中的 Tesseract 系统依赖。OCR 只实现印刷文字识别，公式与中文可能出错，必须手工确认。原图仅暂存，自动删除。

## 验证

```bash
pip install -r requirements-dev.txt
python -m pytest -q
PYTHONPATH=. python experiments/run_validation.py --output validation-output
```

实验输入为 120 条合成情境（20 道数学基础题 × 6 种条件），比较四种确定性规则策略；不是学生实验或 LLM 消融。BKT 参数、候选动作权重均为设计假设，未用真实学生数据拟合。候选动作比较与条件规则当前选择一致，不声称额外学习增益。

## 状态与核验范围

- 题文格式：`(x^2-1)/(x-1)`，单变量 x，多项式分子最高 6 次、分母最高 4 次，原式排除值须为有理数。机器条件输入如 `x!=1,x!=-1`。
- 核验最终表达式等价性和原式排除值；自然语言讲解、中间步骤、提示是否泄露答案尚不自动核验。
- 仅已核验、用户声明独立完成的作答更新 BKT；相同题文、作答、条件的再次提交不重复更新。该声明不能证明真实独立完成。
- 临时要求只用于当前请求；长期记忆必须明确确认，冲突保留，允许撤销。
- 每个随机私有链接对应 SQLite 独立记录；版本检查防止并发覆盖。链接是访问凭据，不是登录账号；不要分享链接。正式多人产品需补充账号、权限、加密、删除和持久数据库方案。
- Streamlit Cloud 本机 SQLite 在容器重建时可能丢失，请定期导出。导入数据是用户提供的状态，不能作为成绩认证证据。
- API、输出核验或版本检查失败不会写入本轮题目、对话或知识状态。界面显示“已配置”，实际成功响应写入处理记录。
